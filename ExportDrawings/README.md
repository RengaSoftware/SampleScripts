This script allows you to export drawings from the selected topic to PDF, OXPS and DWG.

Script arguments example:

```
C:/Python/python.exe c:/Projects/SampleScripts/ExportDrawings/export_topic_drawings.py --project "C:/Program Files/Renga Professional/Samples/Workshop.rnp" --topic "АР" --dwg "C:/Projects/" --pdf "C:/Projects/workshop_AR.pdf"
```
